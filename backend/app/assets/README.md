# 블로그 초안 — 얼굴 가림에 쓰는 파일

이 저장소는 공개되어 있다. 여기 두는 것은 그래도 되는 것만 둔다.

## yunet.onnx (232KB)

얼굴 검출 모델. OpenCV Zoo 의 YuNet — **MIT 라이선스**라 그대로 담아도 된다.
`cv2.FaceDetectorYN` 이 이 파일을 읽는다.

Haar cascade 로 먼저 만들어 봤지만 쓸 수 없었다. 실제 시설 사진 14장에서
옷과 바닥에 헛가림이 15군데 생겼고, 정작 거울에 비친 얼굴과 뒤로 젖힌 얼굴은
놓쳤다. 헛가림은 눈에 띄어 지우면 그만이지만, 놓친 얼굴은 아무도 모른 채
블로그에 올라간다.

## smile_sticker.png

얼굴 위에 덮는 그림. 원본 화소를 덮어 다시 굽는다 — 화면에서 가린 척하는 것이
아니라, 파일 자체에 얼굴이 남지 않는다. `face_mask.verify_masked()` 가 덮은
자리를 격자로 훑어 원본과 대조해 실제로 지워졌는지 확인하고, 아니면 그 사진은
쓰지 않는다(원본으로 대체하지 않는다).

## 모델 파일이 없으면

`face_mask.available()` 이 False 가 되고, 기능만 조용히 꺼진다. 서버는 뜬다.
대신 초안은 만들어지지 않고 '가림 실패' 사유가 남는다 — 가리지 못한 사진이
글에 실리는 일은 없다.
