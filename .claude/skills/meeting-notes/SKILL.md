# 회의록 정리 → 내부공지 업로드

카카오톡 채팅방에서 내보낸 대화(txt)를 회의록으로 정리하고, 같이 저장된 사진과 함께
admin 서버의 내부공지(InternalNotice)로 업로드하는 워크플로.

## 폴더

- 받은 파일: `/Users/mac/Documents/01_행복한요양원/회의록/` — 사용자가 카톡 내보내기 txt 와 사진을 넣어두는 곳.
- 처리 완료: `/Users/mac/Documents/01_행복한요양원/회의록/보관/YYYY-MM-DD_제목/` 로 이동.

## 절차

1. **파일 찾기** — 받은 파일 폴더에서 최신 `.txt` 를 찾는다 (`보관/` 제외). 이미지 파일(jpg/jpeg/png/gif/webp/heic)도 같은 폴더에서 수집한다. txt 가 없으면 사용자에게 카카오톡 내보내기 방법을 안내하고 멈춘다 (`사용법.md` 참고).

2. **대화 파싱** — 카카오톡 내보내기 형식은 두 가지가 있다:
   - PC: `[홍길동] [오후 2:31] 메시지내용`
   - 모바일: `2026. 9. 14. 오후 2:31, 홍길동 : 메시지내용`
   날짜 구분선(`2026년 9월 14일 일요일` 등), 입장/퇴장/사진/이모티콘 시스템 메시지는 걸러낸다. 파일이 크면 회의가 열린 날짜 구간만 읽는다.

3. **회의록 작성** — 아래 형식의 **일반 텍스트**로 정리한다 (admin 은 `whitespace-pre-wrap` 렌더링이라 마크다운 문법이 그대로 보인다. `#`, `**` 금지):

   ```
   ■ 일시: 2026년 9월 14일
   ■ 참석: 대화에 등장한 발화자들

   [주요 논의]
   1. 주제 — 핵심 내용 요약

   [결정사항]
   · 결정된 내용

   [할 일]
   · 담당자 — 할 일 (기한)
   ```

   실제 논의 흐름에 맞게 섹션은 가감한다. 잡담은 빼고 업무 내용만 담는다.
   제목은 `9/14 직원회의` 처럼 날짜 + 회의 성격으로 짓는다.

4. **사용자 확인** — 정리한 회의록 전문과 업로드할 사진 목록, 제목을 보여주고 **반드시 승인을 받은 뒤** 업로드한다. 서버에 게시되는 외부 액션이므로 생략하지 않는다.

5. **업로드** — 회의록 본문을 스크래치패드에 파일로 저장한 뒤:

   ```bash
   python3 backend/scripts/upload_meeting.py \
     --title "9/14 직원회의" \
     --content-file <스크래치패드/회의록.txt> \
     --photos-dir "/Users/mac/Documents/01_행복한요양원/회의록"
   ```

   - 푸시는 기본 발송 안 함. 사용자가 원할 때만 `--push`.
   - 인증은 환경변수 `HAPPY_ADMIN_ID`/`HAPPY_ADMIN_PW` 또는 `~/.happy/credentials.env`. 없으면 스크립트가 안내 메시지를 내며 종료한다 → 사용자에게 관리자 아이디/비밀번호를 물어 `~/.happy/credentials.env` 에 저장(chmod 600)하고 재시도한다.
   - 서버는 기본 프로덕션(`https://api.xn--p80bu1t60gba47bg6abm347gsla.com`). 로컬 테스트는 `--api-base http://127.0.0.1:8010`.

6. **정리** — 업로드 성공 후 txt 와 사진들을 `보관/YYYY-MM-DD_제목/` 으로 이동하고, 공지 id 와 함께 완료 보고한다.
